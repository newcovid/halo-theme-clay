# CJK Serif Webfont Component

## Description

Declares the self-hosted Chinese serif webfont (`Clay Serif SC`, a subset of
Noto Serif SC under SIL OFL 1.1) used by display headings and blockquotes.

Without it, whether a Chinese heading renders as a serif depends on the visitor's
operating system — Windows, macOS and iOS ship one, stock Android does not, so
Android visitors lose the serif/sans contrast that identifies the theme.

The font is split into a common tier and rare-character slices, each with its own
`unicode-range`, so a page downloads only what it actually uses. Assets and the
`@font-face` block are generated by `scripts/build-cjk-serif.py`; see that script
for the tiering rationale.

## Usage

Head Content (for including necessary scripts/styles)

```html
<th:block th:insert="~{components/font-cjk-serif/template :: head}"></th:block>
```
